# NotYet

> Software that remembers why you said no — and tells you when the answer should change.

NotYet turns deferred product decisions into a living watchlist. Capture the original trade-offs, define measurable revisit conditions, and deliberately re-evaluate when the evidence changes.

## Stack

- Next.js
- React
- TypeScript

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Commands

```bash
npm run dev    # local development server
npm run check  # TypeScript validation
npm run build  # production build
```

The dashboard is implemented in `app/page.tsx`; styling is in `styles.css` and is imported by the Next app shell.
